# Andrey Hong — AI Video Creator & Creative Portfolio

> **Creative strategy meets AI-assisted visual production.**  
> An award-winning style interactive creative portfolio featuring WebGL water ripples, 3D perspective cards, dynamic diagonal sections, and fluid micro-interactions.

---

## ✨ Features & Highlights

- **💧 Subtle Water Ripple Engine**: Calm, silky real-time WebGL & 2D Canvas water ripple effect reacting to mouse movements and clicks in the header.
- **🧊 Interactive 3D Perspective Cards**: Tactile cards with smooth perspective tilt, specular glare sheen, and multi-layer parallax Z-depth.
- **📐 Diagonal Slanted Sections**: Striking alternating diagonal section cuts and scroll-driven momentum tilt physics.
- **🎞️ Interactive Video Editing Timeline**: Scrubbable timeline with glowing playhead, live timecode readout, and audio equalizer bars.
- **🎯 Fluid Magnetic Cursor**: Smooth trailing liquid ring with magnetic attraction to buttons and contextual badges (`PLAY ▶`, `VIEW ↗`).
- **📊 Animated Metric Counters**: Stats count up dynamically with smooth easing curves when entering the viewport.
- **🌓 Dark & Light Mode**: Seamless theme switching with adaptive color palettes.
- **🔊 Web Audio API Synthesizer**: Optional realistic water droplet audio toggle (`SOUND: ON/OFF`).

## 🚀 Quick Start

Simply open `index.html` in any modern web browser, or serve locally:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```

Visit `http://localhost:3000` in your browser.
